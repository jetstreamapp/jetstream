## What's new

### Trust certificates installed on this computer

Some companies inspect network traffic through a proxy or firewall that re-signs connections with its own certificate. The desktop app did not trust that certificate, so connecting an org failed with errors such as `SELF_SIGNED_CERT_IN_CHAIN`. Turn on **Settings > General > Trust certificates installed on this computer** to also trust the certificate authorities in your operating system's certificate store (Keychain on macOS, the Windows certificate store on Windows). The setting is off by default and applies without restarting the app.

### Certificate errors explain how to fix them

When connecting an org or calling Salesforce fails because the certificate chain is not trusted, the desktop app now names the error, explains that a proxy is probably inspecting traffic, and points to the new setting. Expired certificates and hostname mismatches still show the general connection error, since trusting another certificate authority would not fix them.

### Other fixes

- Deactivated team members can no longer open the team's billing portal or sign in by linking a new login provider with the same email.
- Long error messages on the query results page now wrap instead of running off the page.
- In the desktop app, changing a setting in a newly opened Settings window no longer shows the other settings as reset to their defaults (the saved values were never affected).
