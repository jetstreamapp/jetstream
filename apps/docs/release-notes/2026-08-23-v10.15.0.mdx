## What's new

### Record limit in Update Records

Each object in Update Records now has an optional **Maximum records to update** field. Leave it blank to update every record that matches your criteria. To work through a large object in chunks, pair the limit with a criteria that stops matching once a record is updated (for example **Only if blank**) and re-run the update. The limit is applied to the query itself, so the impacted record count shown during validation, the Download Records button, and the update all use the same set of records.

### Map one column to multiple fields

In Load Records, a single column from your file can now be mapped to more than one Salesforce field. This includes using the same column both as a field value and as a lookup reference. Previously the column had to be duplicated in the source file.

### Hide unchanged files when comparing metadata

When comparing metadata between two orgs in Deploy Metadata, a new **Hide Unchanged Files** checkbox filters the file tree down to files that differ between the orgs. A "Showing X of Y files" count appears alongside the checkbox.

### Field audit columns in Manage Permissions

The Field Permissions tab in Manage Permissions can now show the created date, created by, last modified date, and last modified by for each field. Turn the columns on from the gear menu on the tab. Exports always include these columns. Standard fields do not have audit information in Salesforce, so those cells are blank.

### Combine repeated query filters into In or Not In

When the query builder detects two or more conditions on the same field that can be combined, it shows a dismissible hint above the filter rows with a one-click conversion:

- **OR** with **Equals** becomes a single **In** condition
- **AND** with **Does Not Equal** becomes a single **Not In** condition

Conditions that use a date picker or a field function are left as-is.

### Other fixes

- Refresh All Orgs now checks fewer orgs at once, which reduces failed health checks on pages with a large number of orgs.
