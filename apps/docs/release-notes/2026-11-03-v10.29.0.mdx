## What's new

### Search settings

Settings now has a search box in the sidebar. Every word you type must match a setting's text or the heading of the group or section it belongs to. Matches are highlighted, and the navigation lists only sections with results. The browser extension settings page uses the same layout and search.

### Bulk download fixes

- Fixed a bug where downloads of extremely large bulk query results could include only partial results.
- Downloading load results (Download All and View All) now fails with an error if any batch cannot be downloaded. Previously a failed batch was skipped, which could pair later results with the wrong source records.
- Zip downloads that hit an error now fail instead of hanging.

### Bulk update with polymorphic lookup fields

Choosing a field from a polymorphic lookup (for example `Who` → `Contact`) as the value source in Update Records or Bulk Update from query results failed when the field exists on only one of the related objects. These fields are now queried correctly.

### Download progress on the app icon

In the desktop app, active downloads show progress on the Dock (macOS), taskbar (Windows) or launcher (Linux) icon, so you can see progress while the window is in the background.

### Other fixes

- Choosing a very large file in Load Records now shows an error message instead of leaving the page waiting with no feedback.
- Create Fields and Deploy Metadata CSV exports now escape values that begin with a formula character, so spreadsheet apps do not evaluate them. Re-importing an exported Create Fields file works as before.
- Access profiles (pre-release, available only for teams): Automation Control history Roll Back, Re-deploy and Review Changes are now disabled, with an explanation, for team members whose access profile does not allow metadata deployment.
- Fixed duplicate customers and duplicate subscriptions being created in some checkout flows.
- Removing a password or unlinking a login method can no longer leave an account with no way to sign in.
- Deleting a team SSO configuration that is not the active one no longer resets the team's SSO provider.
- Team SSO configuration now requires the identity provider URLs to use https.
- Deleting an org group that contains orgs now records an audit entry for each org for team members.
