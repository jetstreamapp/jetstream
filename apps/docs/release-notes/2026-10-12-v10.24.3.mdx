## What's new

### Picklist defaults in the Record Type Picklist Manager

Since version 8.24.0, the Record Type Picklist Manager showed no default value for any field, regardless of what was configured in Salesforce. Deploying a field whose values you edited also cleared its existing default unless you selected it again. Defaults now load correctly and are kept when you deploy. If you deployed changes with this tool since 8.24.0, check that the affected picklists still have the default you expect.

### Other fixes

- Picklist filters using equals or not equals in the Query Builder no longer show a blank option at the end of the value list.
