## What's new

### Large CSV and JSON downloads

Downloading a very large result set as CSV or JSON could fail with "Invalid string length", for example 291,000 records with 111 fields, or records with several long text fields filled to their limit. Jetstream now builds the file in pieces, so it is no longer limited by the browser's maximum string length.

### Full history restored by sync

With history sync turned on, accounts with more than 100 synced records received only part of their history when it was pulled from the server, so query history could look stuck at an older date. This affected signing in on a new browser or device, choosing **Reset Sync**, and clearing site data. All of your synced history is now pulled. If your history still looks incomplete, choose **Reset Sync** in Settings to pull it again.

### Download filename kept while typing

In the download dialog for query results, the filename you were typing could be replaced with the default name and selected again when the results grid re-rendered. A re-render no longer resets the filename or your **Which Records** choice.

### Page button after a My Domain rename

After an org's My Domain was renamed, the extension could pick up the session for the old domain, and the Jetstream button did not show on Salesforce pages. The extension now uses the session for the page's current My Domain. The extension's keyboard shortcuts for opening Jetstream or viewing the current record from a Salesforce page use the same fix.

### Other fixes

- When Salesforce returns an HTML error page instead of data, Jetstream shows a readable message instead of a parsing error.
- On web and desktop, a request to an org whose Salesforce domain no longer exists (usually a deleted sandbox) now says the domain could not be found and suggests reconnecting or removing the org.
