## What's new

### System permissions on desktop and the browser extension

The desktop app and browser extension now include the System Permissions tab in Manage Permissions that shipped for the web app in 10.7.0. You can review and update system permissions — things like API Enabled or Modify All Data — across all of your selected profiles and permission sets in one table, with dependent permissions enabled and disabled for you automatically. System permissions are also included in your permission exports.

### Maintenance and security updates

The web app release includes routine maintenance and security updates, with no changes to how the app works.
