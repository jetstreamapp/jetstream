## What's new

### File downloads no longer fail in long-open tabs

Record downloads, file downloads, and bulk job result downloads could fail with a download error in a browser tab that was left open while a new version of Jetstream was released. Jetstream now loads what it needs for these downloads ahead of time. If loading still fails, the error message tells you to refresh the page and try again.

### Other fixes

- Record Type Manager no longer shows an error when you go back from the editor to the record type list.
