## What's new

### Org dropdown improvements

The org dropdown is easier to read and search:

- Full usernames are shown without truncation, and the dropdown panel is wider to fit them.
- Each org is labeled with its org type, so sandboxes are distinguishable at a glance.
- Searching now matches the username and org ID.
- The org color indicator still shows when an org has a connection error.
- Org Group cards now include a sandbox indicator.

### Paste any Salesforce URL to add a custom domain

When connecting an org with a custom domain, you can now paste the full URL from your browser into a single input and Jetstream extracts the domain, including sandbox domains.

### Other fixes

- Retrying failed records no longer crashes the page on data loads with more than 100,000 records.
- The multi-object load file preview no longer crashes when a spreadsheet contains date cells.
- Fixed an intermittent error that could prevent data history from being saved when Jetstream is open in multiple browser tabs.
