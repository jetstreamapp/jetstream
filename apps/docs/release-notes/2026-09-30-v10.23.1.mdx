## What's new

### Record Type Picklist Manager deploy fix

In Edge and Chrome 154, deploying picklist changes from Record Type Picklist Manager failed because the browser added an XSLT deprecation notice to the generated package files. Salesforce rejected the package with an error about an invalid `div` element. Jetstream now builds those files without the step that triggered the notice, so the deployment no longer depends on the browser.

In Firefox 155, the same deployment failed earlier, with "There was an error preparing your deployment package." That is fixed as well.
